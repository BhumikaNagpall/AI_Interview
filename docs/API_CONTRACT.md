# Implementation contract v1
Node.js >=24. SQLite via node:sqlite, native HTTP and native browser ES modules; no package installation required. This first increment is repository development, not hosted publication. Six rounds and four personalities. No code execution on host.

## Backend
server/app.js exports createApp({dbPath, engine?}) => { server, close } (server is unlistened http.Server); server/index.js starts on HOST=127.0.0.1 PORT=3000. Default db data/interview.sqlite. Engine injection defaults to server/engine.js exports. Static public/ served with CSP, no inline scripts. API responses JSON. Errors {error:{code,message}}. POST JSON only and same-origin validation; httpOnly session cookie; scrypt passwords; random session tokens stored hashed with expiry; per-user ownership; bounded payloads. GET /api/health => {status:'ok',mode:'practice'|'ai'}. Auth register {name,email,password}, login {email,password}, logout -> {user?}; GET /api/me => {user:{id,name,email}|null}. GET /api/catalog => catalog below. GET /api/sessions => {sessions:Session[]}. POST /api/sessions accepts {role,round,persona,difficulty,durationMinutes,context}; POST /api/sessions/:id/answers {answer,expectedTurnCount}; POST /api/sessions/:id/finish {}; GET /api/sessions/:id; DELETE /api/sessions/:id. Single GET/create/answer/finish returns {session:Session}. Duration 10,20,30; max questions 4,6,8 respectively. Context max 12000; answer max 12000. Allow answer saved before generation failure; error recovery retry can submit same expectedTurnCount and identical answer, no duplicate; GET session reveals state. Concurrency guarded per session. Completed sessions immutable except deletion. Persist report and mode; delete cascades session turns/report. Coding answer is text only, never executed.

Session {id,role,round,persona,difficulty,durationMinutes,context,status:'active'|'completed',mode:'practice'|'ai',createdAt,updatedAt,maxQuestions,turns:Turn[],report:null|Report}. Turn {question,answer:null|string}; latest unanswered question is displayed. If answer stored but generation failed, last turn is answered; retry same payload to continue. Finish evaluates answered turns only and requires at least one answer. Never reveal internal provider errors/keys. Do not expose other users' sessions.

## Engine — server/engine.js
exports catalog = {roles:[{id,label}],rounds:[{id,label,description}],personas:[{id,label,description}],difficulties:[{id,label}],durations:[10,20,30]}; roles software,aiml; rounds hr,projects,dsa,cs,ml,behavioural; personas supportive,formal,detail,challenging; difficulties beginner,intermediate,advanced.
exports getMode() -> practice or ai (AI_API_KEY + AI_MODEL configured, otherwise practice; invalid partial configuration must error clearly).
exports async nextQuestion(session) -> string (called with zero turns for first question, or all existing turns answered for next); exports async evaluate(session) -> Report. Server pins mode per session; engine honours session.mode. Practice deterministic questions/followups, explicitly no technical accuracy scores. AI OpenAI-compatible chat completions using AI_BASE_URL default https://api.openai.com/v1; AI_API_KEY; AI_MODEL required, never hardcode model. Validate structured response, bounded timeout, no silent practice fallback after provider failure. No key exposed to client.
Report {mode,summary,criteria:[{name,score:null|number,outOf:5,evidence:string,improvement:string}],strengths:string[],improvements:string[],nextSteps:string[],disclaimer:string}. Practice scores null and rubric-based reflection prompts; no correctness claims. AI criteria rubric independent of persona and evidence quotes grounded in actual answers. All external/user content untrusted data.

## Frontend — public/index.html, styles.css, app.js
Use API contract exactly, no build dependencies; app.js ES module. Product name Interview Studio. Polished warm off-white, deep navy, restrained violet accent, sidebar + dashboard, six interviewer cards, personable but no external images/fonts needed. Full login/register; setup, session conversation, finish, report/history/delete, responsive mobile. Practice badge and concise honest explanation. Persist only UI state/session id locally, never passwords/transcripts. Safe DOM textContent for user/model text. Optional .txt context upload max 48KiB with extracted text max12000 and paste option, no unsupported PDF claims. Coding textarea with label 'Code review only — not executed'. Retry generation errors without losing answer. Keyboard accessibility/loading/error states. Interview duration is planned session length, question budget enforced rather than claiming countdown cut-off.

## Testing
node --test, tests/*.test.js; backend integration uses ephemeral server + temp SQLite. Engine tests provider injection/mocked fetch only. Do not contact paid AI without key/user setup. Browser QA where available. Git task branches and commits, no GitHub writes by subagents; root publishes reviewed PRs.
